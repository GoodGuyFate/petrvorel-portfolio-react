# Petr Vorel Portfolio

A minimalist photography and painting portfolio for artist Petr Vorel, built with React + Vite and deployed on Vercel.

## Features

- Split-screen layout with fixed sidebar navigation
- Photography and paintings albums fetched dynamically from Flickr API
- Swipeable image gallery with keyboard navigation support
- Hover-based photo preloading for near-instant album browsing
- About and Contact sections with functional contact form
- Fully responsive for desktop, tablet, and mobile

## Tech Stack

- React + Vite
- Swiper.js for touch/keyboard navigation
- Flickr API via Vercel serverless functions (API key never exposed to client)
- Vercel for hosting and deployment
